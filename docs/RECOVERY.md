# Recovering a saved background operation

The companion keeps a private local journal for each reviewed background operation. Operation history is available only after the companion verifies the selected TV and active user. The history list shows safe summaries: operation ID, phase, companion-owned setting names, collection count, and validated result metadata. It never returns the saved identity, local journal path, setting values, or collection manifests. The list examines at most 1,000 JSON records and skips malformed, unreadable, oversized, or unsupported records while retaining valid entries. Each record is limited to 1 MiB. A generic unreadable count and truncation indicator explain when the local history is incomplete.

If an operation is marked **Outcome uncertain**, choose **Reconcile with TV**. Reconciliation asks the TV for the saved operation result and compares the current state; it does not activate or retry the operation. If the result remains uncertain, reconnect and reconcile again. Any retry of a saved activation is a separate, explicit action after reconciliation. Operations requiring review must be reviewed against the current TV state before another change is planned.

To undo a verified operation, choose **Review restore**. The companion prepares a new restore operation from the private baseline and checks that companion-owned settings still match the verified change. The review lists which owned settings and collection updates would be restored. A later manual TV change is kept and causes a conflict. The baseline remains on this computer. Nothing is sent until **Apply reviewed restore** is selected; that action creates a normal journaled operation with its own result and recovery state.

If the selected TV or active user cannot be verified, history is cleared from the view and no recovery action is allowed. Refresh the TV connection and open history again. Corrupt or oversized local journal records are skipped; their filenames and contents are not shown. A restore conflict should be resolved by keeping the current TV state and preparing a fresh plan from the current state.
